# Установка и запуск тестов

## Требования
1. __Python 3.14__
2. __Браузеры Chrome и Firefox__
3. __WebDriver__ (устанавливается автоматически через Selenium)

## Установка
Убедитесь, что  у вас установлен Python 3.14 и менеджер пакетов pip.
Проверить версии можно командами:
'''python --version'''
'''pip --version'''
Подключить пакет  'allure-pytest':
'''pip install allure-pytest'''

## Запуск тестов
1. Перейдите в рабочую директорию проекта (lesson_10):
'''cd lesson_10'''
2. Запустите тесты с сохранением результатов в папку allure-results
'''pytest --alluredir=allure-results'''
После выполнения тестов в директории появятся файлы с результатами.

## Генерация отчёта Allure
Чтобы открыть отчёт Allure, выполните команду:
'''allure serve allure-results'''
Отчёт откроется в вашем браузере автоматически.
В нём будет отображаться статистика прохождения тестов и дополнительная информация.
